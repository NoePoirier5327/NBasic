# La borne principale
En NotSoBasic le bloc de code qui sera exécuté automatiquement par l'interpréteur (un peu comme le `int main()` en c) se compose comme suit :
```
program nom_du_programme

end program
```
Tout ce qui sera entre `program` et `end program` sera exécuté par l'interpréteur.
